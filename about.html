📌 Internship Overview & Progress

About Simple Blog Management System

Developed as part of the Full Stack Web Development Internship to demonstrate clean code, RESTful API architecture, HTML5 semantics, custom CSS UI design, and JavaScript form validation.

Day 1 – Environment Setup

Configured VS Code, Node.js, Express server initialization, Git version control, and Postman API testing collection.

Day 2 – HTML & UI Structure

Crafted semantic HTML5 Home page, Add Blog page, responsive navigation bar, and multi-column footer layout.

Day 3 – Custom CSS & Lite UI

Styled sticky navbar, responsive blog cards grid, modern form fields, buttons, and custom design tokens.

Day 4 – JS Validation & DOM

Implemented client-side form validation, error feedback, real-time counters, category filtering, and toast alerts.

Day 5 – Express GET/POST API

Created Express server routes (GET /api/blogs, POST /api/blogs, DELETE /api/blogs/:id) with CORS and request logging.

Day 6 – Add Blog Tasks (JS Array)

Built API to accept blog creation requests and dynamically store blog objects in an in-memory JavaScript array (`blogs[]`).
